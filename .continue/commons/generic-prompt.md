# Contexto inicial

Utilize como fontes iniciais:

@repository-map

`docs/assessment/01-discovery.md`

O `01-discovery.md` contém o conhecimento consolidado da etapa
anterior do assessment.

O repository map deve ser utilizado para:

- localizar componentes mencionados no discovery;
- identificar arquivos relacionados aos fluxos analisados;
- localizar repositories, clients, services e configurações relevantes;
- determinar quais evidências primárias precisam ser analisadas.

O repository map não comprova o comportamento interno dos componentes.

Não conclua comportamento apenas pela existência ou pelo nome
de arquivos, classes, métodos ou diretórios.

Quando uma conclusão depender da implementação, analise ou solicite
o conteúdo da evidência primária correspondente.
