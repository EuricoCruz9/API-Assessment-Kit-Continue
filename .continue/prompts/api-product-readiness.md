# PROMPT — API Product Readiness

## Objetivo

Avaliar a capacidade da API de ser reutilizada por novos clientes.

Utilize:

* `@repository-map`
* `docs/assessment/01-discovery.md`
* demais documentos do assessment quando relevantes.

---

## Etapas

### 1. Ler o discovery

Identifique:

* domínio;
* endpoints;
* integrações;
* componentes;
* configurações.

### 2. Investigar acoplamentos

Procure evidências de elementos específicos de cliente.

Não inferir acoplamento sem evidência.

### 3. Investigar configurabilidade

Determine se adaptações dependem de:

* código;
* configuração;
* infraestrutura.

### 4. Avaliar contrato

Analise:

* versionamento;
* estabilidade;
* reutilização.

### 5. Gerar classificação

Utilize a escala de 1 a 5 definida pelo agente.

### 6. Gerar roadmap mínimo

Apresente o menor conjunto de mudanças necessário para atingir o próximo nível.
