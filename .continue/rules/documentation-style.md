# RULE — Estilo de Documentação

## Idioma

Toda documentação deve ser escrita em Português (Brasil).

Não traduzir nomes de classes, métodos, endpoints ou tecnologias.

---

## Público-alvo

Escrever documentação que possa ser entendida por:

* desenvolvedores;
* arquitetos;
* TPMs;
* Tech Leads;
* Staff Engineers.

Evitar jargões desnecessários.

---

## Estrutura

Sempre utilizar títulos claros.

Utilizar listas quando facilitar leitura.

Utilizar tabelas para comparações.

Utilizar blocos "Evidência" quando citar código.

---

## Linguagem

Preferir linguagem objetiva.

Escrever fatos antes de opiniões.

Separar observações de recomendações.

---

## Não fazer

* Não reescrever código inteiro.
* Não documentar comportamento não observado.
* Não criar diagramas imaginários.
* Não inventar fluxos.
