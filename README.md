# API Assessment Kit — Continue

## Objetivo

Este kit auxilia na análise técnica de APIs existentes utilizando o Continue em modo Chat.

O foco é produzir documentação técnica confiável e identificar oportunidades de evolução da API sem realizar suposições.

## Fluxo recomendado

1. Descobrir a arquitetura da API.
2. Documentar endpoints e componentes.
3. Avaliar escalabilidade.
4. Avaliar resiliência.
5. Avaliar observabilidade.
6. Avaliar segurança.
7. Avaliar camada de dados.
8. Avaliar reusabilidade para novos clientes.
9. Consolidar um relatório técnico.

## Princípios

* Evidence First.
* Ask, Don't Assume.
* Fact before Recommendation.
* Ausência de evidência não significa ausência de funcionalidade.

## Resultado esperado

Ao final da análise, deve existir um relatório técnico contendo:

* arquitetura atual;
* responsabilidades da API;
* riscos encontrados;
* gargalos identificados;
* melhorias recomendadas;
* pontos que precisam de validação.
